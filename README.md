# Deep Learning Traffic Signs

A practical deep learning project for classifying traffic signs using PyTorch and the German Traffic Sign Recognition Benchmark (GTSRB).

## Objectives

- Explore and understand the dataset
- Build a data preprocessing pipeline
- Train a neural network for traffic-sign classification
- Experiment with CNNs and data augmentation
- Evaluate model performance

## Technologies

- Python
- PyTorch
- Torchvision
- Jupyter Notebook
- Matplotlib

## Dataset

This project uses the GTSRB dataset.

The dataset is not included in this repository. It is downloaded locally and excluded through `.gitignore`.
